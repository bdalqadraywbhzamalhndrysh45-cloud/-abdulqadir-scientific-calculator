# آلة عبد القادر العلمية — PWA

نسخة ويب مستقلة عن تطبيق Android الأصلي. ملفات ثابتة بلا خادم خلفي.

## النشر على Vercel
- استورد مستودع GitHub: `bdalqadraywbhzamalhndrysh45-cloud/-abdulqadir-scientific-calculator`
- اجعل **Root Directory** = `web`
- Framework Preset: **Other**
- Build Command: اتركه فارغًا
- Output Directory: اتركه فارغًا أو `.`
- Deploy.

بعد النشر افتح الرابط على Android من Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». يلزم فتح الموقع مرة مع اتصال بالإنترنت حتى تُخزّن الملفات للعمل دون اتصال.

## الوظائف
العمليات الأساسية، الأقواس، الأسس، الجذور، sin/cos/tan، ln/log، π، e، النسبة المئوية والمضروب. يمكن تبديل DEG/RAD. الحسابات تنفذ محليًا دون إرسال تعبيرات المستخدم إلى خادم.

محرك مختبر الدوال موجود محليًا في `math-engine.js` ولا يعتمد على مكتبات CDN: يدعم تقييم الدوال، الاشتقاق الرمزي للقواعد الشائعة، النهايات العددية التقريبية، ورسم الدوال. عند تحديث النسخة المنشورة، أغلق التطبيق وافتحه مجددًا مع الإنترنت مرة واحدة ليحدّث Service Worker الملفات المخزنة.
